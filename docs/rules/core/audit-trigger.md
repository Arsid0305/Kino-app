# Audit — триггеры и канон

_Rule: path-scoped (при триггере). Источник: AI_OS/SYSTEM.md §8bis._

## Триггеры

Слова: «аудит», «прогони аудит», «проверь весь репо».

## Каноны

- **Универсальный чек-лист** (10 секций, применим ко всем 9 репо) — `llm_wiki/wiki/audit-universal.md`
- **Промпт-шаблон запуска** — там же, секция «Как запускать аудит» (скопировать и подставить `<REPO_NAME>`)
- **Проектная специфика** — `<repo>/docs/AUDIT_PROMPT.md` (тонкий overlay со ссылкой на canon)
- **AI_OS runtime-специфика** — `AI_OS/docs/AUDIT_PROMPT.md`

## Формат вызова

- Через субагента `@repo-auditor` (5 pass, весь чек-лист) — **предпочтительно**.
- Либо инлайн с промпт-шаблоном из canon.

## После аудита

Фиксить по приоритетам **BLOCKER → HIGH → MEDIUM → LOW**. Обновлять `CLAUDE.md` «Открытые баги» и `tasks/lessons.md` при повторяющихся уроках.

## Anti-abuse

Массовые аудиты — по 1-2 репо/день, не за одну сессию (см. `github-anti-abuse.md`).
